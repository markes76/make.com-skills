# Scenario Evaluations

These are agent-behavior acceptance cases, inspired by the useful evaluation-first practice in mature skill packs. They do not call a live Make account and cannot prove a connector's behavior; live schema and official current sources remain authoritative.

Each JSON file must contain a stable ID, the relevant reference(s), a realistic request, expected observable behavior, and safety checks. Run `python3 scripts/validate_evaluations.py` to validate their structure.

# Community Brand Usage

Make's public brand guidance describes its own purple-to-pink domino mark and wordmark. This repository does not copy, modify, or combine those marks. Its `make-skills-cli-mark.svg` uses a different visual idea—an original terminal prompt and routing signal—so people can distinguish the community companion from Make's official product.

The GitHub README must keep the statement **“Unofficial community companion · use at your own risk”** near the mark and describe the official `make-cli` separately. Avoid saying or implying that Make.com certifies, supports, sponsors, or guarantees this repository.

The generated hero is intentionally abstract. Do not overlay a Make logo, use Make's proprietary logo kit, or present a screenshot as though it were an official product interface. For the legal/operational boundary, see [COMMUNITY_NOTICE.md](../COMMUNITY_NOTICE.md).

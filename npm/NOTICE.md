# Unofficial Community Companion

This npm package is an independent community bridge for the Make.com Skills repository. It is not an official Make.com package, is not the official `make-cli`, and is not affiliated with, endorsed by, or supported by Make.com unless Make.com states otherwise.

It launches a bundled companion that uses a separately installed official Make CLI. Review every plan and command before approving it. The package provides no guarantee of correctness, compatibility, security, or third-party automation outcome; it never grants authorization for a Make mutation. See the repository's `COMMUNITY_NOTICE.md` and `LICENSE` for the full notice.

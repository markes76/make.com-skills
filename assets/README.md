# Visual Assets

- `make-skills-cli-mark.svg` is the editable, original community mark: a terminal prompt connected to routing nodes. It intentionally does not reuse Make.com's domino logo, wordmark, purple/pink gradient, or brand lockup.

Use these assets only with the clear “Unofficial community companion” notice. Do not place the mark beside Make's official logo in a way that suggests endorsement or affiliation.
